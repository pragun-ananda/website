## Why another blog?

I've been meaning to write more about the things I work on. This blog is an experiment in thinking out loud — mostly about AI, systems, and infrastructure.

The goal is to explain ideas clearly, with enough math and code to be useful, but without the formality of a paper.

## What to expect

- **Technical walkthroughs** of papers and architectures
- **Infrastructure notes** on building ML systems
- **Short posts** on tools and techniques I find useful

Let's see where this goes.
